# 秋收祭出场伙伴第二特性

五位伙伴均在突破 1 次后解锁第二特性。已达到突破阶段的存档自动生效，无需领取；原有第一特性保留。伙伴详情、突破预览和自选伙伴界面使用「突破 1 次解锁」；已解锁特性在详情标为「已解锁」。

| 伙伴 | 特性 | 游戏内描述 |
| --- | --- | --- |
| 蕾蕾 | 丰厩之赐 | 驻场畜牧时，普通产物数量提高25%，不足一件的部分累计至后续周期。 |
| 洛纳莉 | 丰野馈赠 | 采集物产抽取次数增加30%，额外次数向下取整，至少增加1次。 |
| 古剑喵 | 踏雪无痕 | 本人执行非全体的敏捷检定时，调整值＋2。 |
| 麻咪 | 熟稔农时 | 农作最终耗时减少8%，可突破最低耗时限制。 |
| 灼焱 | 烈焰连袭 | 每场战斗首次命中后，立即追加一次攻击；若目标已倒下，则攻击下一名存活敌人。 |

## 结算约定

- 生产任务开工时冻结特性；进行中的任务不追溯修改。采集先计算既有抽取次数（最多 60），再增加 30%，新上限为 78。
- 畜牧周期保持 8 小时。普通产量加成沿用每只动物的小数累计；耗料与特殊产物概率不变。存储上限按加成后的周期产量计算，保持原本可积累的周期数。先结算旧参数，再刷新下一段参数；驻场伙伴突破时同样遵守此顺序。
- 探索和探秘出发时冻结可用特性列表。旧的进行中路线只使用原有基础特性，下一次出发启用新增特性。
- 连击独立掷命中、伤害和暴击，沿用武器效果；不额外推进回合，不重复使用已消耗的饰品优势骰。首次未命中不消耗连击，使用记录随战斗存档保存，每场重置。

活动原有起止时间保持不变。

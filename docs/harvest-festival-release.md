# 丰收祭发布口径与修复

本次基于社区 PR #4（`f7a013d`），保留三桌、两套皮肤和五位常驻角色轮替的内容方案。

## 档期

- 按北京时间，开始时间为实际发布时刻，不能回拨到当天 00:00。
- 结束时间为上线日期加 45 天的 04:00，结束时刻不再接受交菜、皮肤兑换或招募。
- 例如 2026-11-06 15:20:30 发布，结束为 2026-12-21 04:00:00。
- 蕾蕾、洛纳莉、古剑喵、麻咪、灼焱依次轮替，各三次，总计十五期。
- 第一期从上线时刻到上线日期加三天的 04:00；此后每三天 04:00 换期。最后一期到活动结束，不增加只有数小时的第十六期。
- 每桌每日交菜额度仍为四份，日界沿用每日委托的北京时间 04:00。

首次发布前的模板设为 `enabled: false`，准备代码不提前计时。当前正式配置已启用并记录下文实际档期；后续部署保留此配置。夏活档期未改动。

以下为首次发布操作记录，现已执行；已启用后不可再次运行排期写入命令：

```bash
# 仅预览，不写配置
python3 scripts/schedule_harvest.py

# 正式上线时运行一次，取该时刻并原子写入 seasons.json
python3 scripts/schedule_harvest.py --write
```

若需要使用发布操作已记录的准确时刻，可传 `--launch-at '2026-11-06T15:20:30+08:00'`。脚本拒绝不带时区的输入。已启用的档期拒绝重复写入，重启和重新部署不自动重新计时；后续部署应保留已发布的 `seasons.json`，不能用仓库中的待发布模板覆盖。
